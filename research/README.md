# Opace AI Content Integrity: foundation research snapshots

This directory publishes the first-party research briefs that pre-date or sit outside the implementation repository's measured workstreams. They are included for discovery, traceability and review. Each file is a dated snapshot, not an automatically current product claim.

Start with the [complete research index](../docs/RESEARCH-INDEX.md). It links the current architecture, all measurement reports, all model and corpus workstreams, the 21 readable research papers and every file in this directory. For a current product claim, use the [technical architecture and claim boundaries](../docs/AI-CONTENT-INTEGRITY-TECHNICAL-ARCHITECTURE.md) before an older brief.
