Four screens, now in Opace's own design language

The first pass fixed the reading load and built its own token set to do it. This pass throws that token set away and rebuilds everything on the live site's tokens, then turns the four heaviest blocks of text into pictures.

01 / What changed since you last looked

Three things

Everything else survives from the first pass, including every published number and every refusal.

It looks like Opace now

Paper, cream panels, the black hero with its grid, Outfit headings with an orange emphasis word, numbered section eyebrows, pill buttons, 22 px panels. Every value read out of the live stylesheets, not matched by eye. The brand orange is back at #fb700a, unchanged.

The evidence is drawn

Your document, cut into sections, each with its own bar and one flag line across all of them. The accuracy figures as proportion marks with their denominators showing. Six checks as a status strip. The watermark as one sentence and a dot on a line.

The numbers are corrected

A corpus measurement landed after the first pass was built. Detection is 95.1%, not 90.6%. Fiction false positives are 11.2%, not 6.15%. Every figure now says long-form, because short web copy has no measurement at all.

The main one, and the screen to look at first. Six states along the top: empty, pasted, running, a middle result, a flagged result, and a draft too short to read. 05 / What did not change

The honesty, intact

None of this was traded for the shorter page.

Every number is still on screen, including the bad ones

The false-positive rate on fiction is published with its denominator, which no competitor does anywhere a visitor can see it. It has moved out of a warning box and onto a methods plate beside the result, because a warning frightens and a methods plate reads as competence.

The refusals

Short text still gets nothing rather than a guess. A check that did not run is still never counted as a pass, and now has its own visible state rather than a missing row. The receipt showing what was sent is still there.

Three separate answers

AI patterns, hidden characters and writing quality stay three answers, with three shapes, so nobody averages them by eye either.

No number in any level name

The flag point is still under review. Move it and the bars move under a line that stays still. Nothing on the page has to be rewritten.
