# ADR 0004: Licence boundaries

Status: accepted planning baseline; distribution review required  
Date: 2026-08-26

Opace-authored non-WordPress code uses MIT. The WordPress distribution uses GPL-2.0-or-later. Research code, models and datasets are separate artefacts whose exact licences and model/data terms must be approved before integration. No unlicensed source is copied. GPL WordPress code does not enter the MIT core.
