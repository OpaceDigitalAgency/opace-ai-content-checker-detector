# Security policy

Do not place vulnerabilities, source content, tokens, credentials or customer data in a public issue or fixture.

Use the private contact route at <https://opace.agency/get-in-touch/> before the repository's private security-advisory form is available. Include the affected product/version, a minimal content-free reproduction and expected impact.

Supported versions are listed in each released package's security policy or release notes. Implementation security requirements and trust boundaries live in `docs/security/THREAT-MODEL.md`. Opace does not accept private documents or credentials as test evidence.
